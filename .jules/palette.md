## 2024-03-22 - Visual Layouts vs Semantic Structure
**Learning:** React/Tailwind components often achieve the visual appearance of a "label" next to an "input" using structural components like flexboxes, without actually programmatically associating them (e.g., using `htmlFor` on a `<label>` or `aria-label` on the `<input>`). In highly styled "cyberpunk" UIs like this one, it's easy to focus solely on aesthetics and forget that screen readers cannot interpret a nearby `<span>` as a label for a `<input type="range">`.
**Action:** When auditing or building custom UI components (like settings modals or command bars), explicitly check if visual text elements are semantically linked to their interactive counterparts. Always ensure form elements have either an explicit `<label>` or an `aria-label` attribute.
